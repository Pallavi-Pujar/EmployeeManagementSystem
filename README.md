# Employee Management System

A beginner Java full-stack project. The browser page is HTML, CSS, and JavaScript. Spring Boot exposes a REST API. MySQL stores the employee records.

## What you can do

- Add an employee (name, email, department, salary). The ID is generated by MySQL.
- See every employee in one table.
- Update an employee.
- Delete an employee.

## How the pieces connect

```text
Browser (index.html + app.js)
        |  fetch /api/employees
        v
Spring Boot REST API (EmployeeController)
        |
        v
EmployeeService  ->  EmployeeRepository
        |
        v
MySQL database employee_db, table employees
```

Open the site at `http://localhost:8080`. Spring Boot serves the page and the API from the same place, so the page can call `/api/employees` directly.

## Project map

| Path | Role |
| --- | --- |
| `src/main/java/com/ems/model/Employee.java` | Database table, mapped by JPA |
| `src/main/java/com/ems/dto/EmployeeRequest.java` | JSON body for create and update, with validation |
| `src/main/java/com/ems/repository/EmployeeRepository.java` | Spring Data methods that talk to MySQL |
| `src/main/java/com/ems/service/EmployeeService.java` | Create, read, update, delete rules |
| `src/main/java/com/ems/controller/EmployeeController.java` | REST endpoints |
| `src/main/resources/static/` | The web page |
| `src/main/resources/application.properties` | Port, MySQL URL, username, password |
| `database/employee_db.sql` | Optional script if you want to create the table in Workbench |

## Step 1. Install the tools

You need:

- JDK 21
- Maven
- MySQL 8

Check them:

```powershell
java -version
mvn -version
mysql --version
```

## Step 2. Set the MySQL password

On this computer the MySQL service is `MYSQL80` and it listens on **port 3307**.

Open `src/main/resources/application.properties` and set your real root password:

```properties
spring.datasource.username=root
spring.datasource.password=your-mysql-password
```

You can also pass it only for one run, without editing the file:

```powershell
$env:DB_PASSWORD = "your-mysql-password"
mvn spring-boot:run
```

If MySQL on another computer uses port 3306, change `3307` to `3306` in the datasource URL.

The app creates the `employee_db` database and the `employees` table on startup. You can also run `database/employee_db.sql` yourself in MySQL Workbench.

## Step 3. Start the application

From this folder:

```powershell
mvn spring-boot:run
```

Wait until the log says `Started EmployeeManagementSystemApplication`. Then open:

[http://localhost:8080](http://localhost:8080)

## Step 4. Use the page

1. Fill in name, email, department, and salary, then choose **Save employee**.
2. The new row appears in **All employees**. The ID comes from the database.
3. Choose **Edit**, change the fields, then **Update employee**.
4. Choose **Delete** and confirm.

The search box filters the table in the browser. It does not delete anything.

## REST API

| Action | Method | URL | Body |
| --- | --- | --- | --- |
| List all | `GET` | `/api/employees` | none |
| Get one | `GET` | `/api/employees/{id}` | none |
| Add | `POST` | `/api/employees` | JSON |
| Update | `PUT` | `/api/employees/{id}` | JSON |
| Delete | `DELETE` | `/api/employees/{id}` | none |

Example body:

```json
{
  "name": "Asha Menon",
  "email": "asha@example.com",
  "department": "Engineering",
  "salary": 45000
}
```

Email must be unique. Salary cannot be negative.

## If something fails

**Access denied for user 'root'**  
The password in `application.properties` does not match MySQL. Put the same password you use in MySQL Workbench.

**Communications link failure / port 3306**  
This MySQL server uses port `3307`. Confirm the port in Workbench, then match it in `spring.datasource.url`.

**Port 8080 was already in use**  
Stop the other program, or set `server.port=8081` and open `http://localhost:8081`.

**The page says it could not load employees**  
The browser opened the HTML file directly, or Spring Boot is not running. Start the app and use `http://localhost:8080`.
